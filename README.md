# RAG Model and Medical Data Processing

This project processes patient JSON files and shows summarized patient information through a website.
Note: the originally provided JSON files had errors, so please use the JSON files in this project.

## Features
- **Replication:** generate outputs similar to the original data.
- **Parsing CSV files:** process and analyze CSV files for data preparation.
- **Prompt creation for LLMs:** generate input prompts for large language models.
- **Flask web application:** simple user interface for the project.
- **HTML and CSS design:** styling for the interface.

## Links
- Current website for uploading patient JSON data and getting summarized patient information: [Patient Portal - Render](https://helia-patient-portal.onrender.com)
- Future website with more functionality: [Patient Portal - Builder Preview](https://patient-portal-yrdq1xv3y4hn074m.builder-preview.com/)

## Main Files
- **`app.py`:** main script that runs the project and displays data on the website.
- **`analysis_5.py`:** extracts data from any JSON file and saves it in an Excel file. By default, it processes files ending with `fixed`.

## Other Files
- Files starting with `analysis` with numbers less than 5 were used in the early stages of the project. They are kept for reference but are not needed for the final version.
- JSON files with `parse` in their names are generated by the main script.
- The main provided datasets are the three JSON data files.

## How to Run
1. Install the required libraries.
2. Run `app.py`.

## Deployment

The app is deployed on Render. Deployment files are in [helia-patient-portal](https://github.com/Helia-Karisani/helia-patient-portal).

Project structure for deployment:
```
Procfile
app.py
requirements.txt
static/style.css
templates/index.html
templates/results.html
```

`Procfile`:
```
web: gunicorn app:app
```

`requirements.txt`:
```
Flask==3.1.0
gunicorn==23.0.0
pandas==2.2.3
openai==1.59.7
```

Render clones the GitHub repository, installs the dependencies from `requirements.txt`, and runs the app using the `Procfile`.
